# Public structured pilot limitations

Six authored worlds, 18 checkpoints. Structured facts and exact-value claims, not free-text extraction or QA. Reference controls are deterministic and do not measure BrainBob or a trained model. No hidden cases, independent human annotation, production authentication, cache/history/HTTP isolation, physical erasure, concurrent writes, historical time parsing, token budgets, latency deadlines, stochastic repetitions or full Core coverage are established. Gold is withheld from adapter calls, but Python adapters are trusted code in the evaluator process, not sandboxed adversaries. Exported events describe delivery receipts, not inspected internal state transitions. A candidate ingestion crash aborts the run; it is not a success or silently dropped world.
