# Solution diagram

`memory-simple.png`, `memory-simple.svg`, and the editable `memory-simple.mmd` are copied unchanged from the [published diagram](https://github.com/jerelvelarde/BrainBob/tree/373eee2e11891e43232ae509c1d7de9ae3567e3a/diagrams), originally added by Bonan and extended with the evaluation loop in commit `12b2452`.

The diagram is a conceptual loop. Write-time changes obey authority, scope, date, and lock rules. Usefulness review needs task grades and confirming evidence before ordinary retirement; it is not a claim that every chat automatically triggers evaluation. The current component flow and model assignments are in [architecture.md](../docs/architecture.md).
