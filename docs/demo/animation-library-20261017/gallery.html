Conversation

episode.ingested

A conversation sheet arrives. This is a recorded-ingestion cue; it does not run extraction itself.

Create

memory.added

Bob writes and files a candidate that the backend accepted as a new memory.

Retrieve

memory.retrieved

A runner goes to the appropriate tier cabinet and brings back a tabbed file.

Session file

session context returned

A runner delivers a file to Maya’s desk. Real session context combines relevant, accessible individual, team, and organization records. This single-file scene illustrates delivery, not three separate retrieval calls.

Update

memory.added with supersedes / linked correction

Bob pulls the old record, writes at the desk, and files its replacement. The new immutable memory supersedes the old one; history remains available.

Retire / delete

memory.retired

Fire fills the office; papers arc into the shredder and emerge as strips. The effect represents retirement of the selected record. It does not delete the whole store, erase history, or establish that retirement was confirmed.

Evaluator enters

evaluation.started

Evaluator Bob enters from the open right side. Only the evaluator moves into the room; the crew is not mobilized.

Check a citation

memory.checked

The evaluator checks a cited record. This illustrative cue uses unchanged: no with/without correctness flip. It is not an executed evaluation result.

Evaluator leaves

evaluation.finished

Evaluator Bob leaves once the cited-memory checks finish. This does not mean every memory in the brain was audited.

Promote

memory.promoted

A golden record rises toward the trusted shelf. Status changes; claim text is not rewritten.

Flag

memory.flagged

A red flag marks an owner-review concern. The locked memory remains present.

Lock

memory.locked

A padlock identifies an owner-protected record. Harmful locked records are flagged instead of automatically retired.

Owner keeps it

memory.resolved — keep

The recorded owner keeps a flagged memory. Correct and retire resolutions use their corresponding operations.

Reject

memory.rejected

An incoming paper bounces back. The candidate does not become a new active memory.

Answer

answer.produced

An answer packet is delivered with its source records; actual response text and citations appear in chat.

Retirement preserves history. A flag asks the owner to review. Animation makes a recorded operation visible; it never authorizes the operation.
